- RiskExecution observation template: `data/contracts/v101_execution_observation_template.csv`
- MarketEvidence news template: `data/contracts/v102_news_evidence_template.csv`
- Broker contract: `config/v101_broker_execution_contract.yaml`
- MarketEvidence contract: `config/v102_market_evidence_contract.yaml`
- Live execution: `BLOCKED`

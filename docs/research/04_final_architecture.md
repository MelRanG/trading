## 핵심 결론

**B안을 선택한다. Hermes의 세션 검색·작업 위임·스킬 버전 관리 설계를 선택적으로 차용하고, 런타임은 읽기 전용 연구 Shadow에서 증분 가치가 확인될 때 도입한다.** 가장 큰 기대효과는 여러 분기에 걸친 가설을 다시 찾고, 아직 결론이 나지 않은 연구를 근거와 함께 이어가는 데 드는 비용을 낮추는 것이다. 선행 신호 발견, 예측 오차 개선, 순초과수익은 별도 검증 대상이다.

## 목표 구조와 저장 경계

```text
공식 공시·IR·경쟁사·가격·기대치 → 시점별 원문 스냅샷
     ├─→ 독립 발굴/예측 → 봉인된 논거·반론 → Shadow 판단
     └─→ 동결 전략 → 위험 게이트 → Paper intent·fill → 대사·NAV
          └─→ 성숙한 실제 결과 → 전략별 독립 복기
                   → Factory 후보 등록 → 격리 평가 → 인간 승인
```

| 저장 계층 | 권위와 쓰기 주체 |
|---|---|
| 에이전트 메모리 | 업무 진행, 방법, 연구 ID 포인터, 세션 요약. Hermes 또는 현행 체크포인트가 관리. 잊거나 수정해도 공식 판단에는 영향이 없어야 함 |
| 투자 연구 기록 | 원문 해시·최초 관측 시각, 정정 계보, 가설·확률·반례·1/2/4분기 및 장기 예측, 기대치·입력/모델/스킬 버전, 검증 예산. 독립 등록기가 append하고 정정은 원본을 참조 |
| 거래·평가 원장 | 세션·target·intent·client_order_id, 체결·비용·현금·포지션·NAV·대사, 당시 입력 해시. 결정론적 실행기와 독립 평가기만 쓰고 Hermes에는 필요한 마스킹 사본만 제공 |

**운영 순서.** 장 시작 전 공식 세션과 수집 상태를 확인하고 가설을 갱신한다. 장중은 승인된 전략과 가격·수량 규칙으로 처리하고 데이터/대사가 미확정이면 HOLD_ONLY를 유지한다. 장 마감 후 평가 가능해진 건만 정산한다. 정기 연구가 새 가설을 등록하더라도 독립 평가와 사람 승인 후에만 후보 상태가 바뀐다. Live hardlock을 유지한다.

**복기 편향 제어.** 1차 평가자는 당시 증거와 계획만 보고 과정 점수를 봉인한다. 2차 평가자는 고정된 실제 결과로 수치 오차·Brier·예측 구간을 채점한다. 계좌 손익은 노출·비용·체결과 나누고, 사전등록한 무거래 또는 같은 위험 예산의 대안만 반사실로 비교한다. 실패·기권·미성숙 건도 보존한다. 자기 전략의 복기와 전략 간 비교·승격은 다른 작업 ID·평가기·접근권한으로 분리한다. 개선 기록은 독립 테스트가 끝나기 전까지 전략 변경 권한이 없다.

**장애·격리.** 각 작업은 시장·세션·전략/입력 해시로 키를 고정하고 체크포인트와 별도 실행 영수증을 남긴다. 다시 시작하면 승인 상태·원장·외부 조회 결과부터 대사하고 미확정 접수는 재발행 전에 상태를 확인한다. 시세 누락·중복·stale, 세션 불일치와 검증 누락은 차단한다. 연구 작업자는 브로커 키·주문 도구·운영 DB 쓰기 권한 없이 독립 프로필과 제한 도구에서 실행한다. 생성 코드/스킬은 별도 작업 디렉터리에서 동결된 읽기 전용 입력·네트워크 기본 차단·리소스 제한으로 평가한다. UI 프로필 분리나 스킬 스캔만으로 권한 분리가 완성되지는 않는다.

## 구현 순서와 검증 계약

기존 경로 유지가 비용이 가장 낮고 대조군을 제공한다. 복구 실패가 국소적이면 부분 교체가 가장 검증하기 쉽다. 전면 재구축은 기존 경로와 부분 수정이 동일 장애 시험에서 반복 실패하고 대안이 Toss/KRX/미장 어댑터·회계·정확한 재시작을 동등하게 입증한 경우에만 재평가한다. 앞선 17개 단위 시험만으로 전체 운영을 승인하지 않는다.

## 부록 · 실행과 증거의 구분

- **이번 실측.** 고정 소스에서 메모리의 고유 매칭 함수와 세션 시간 경계 함수를 추출해 Python에서 실행했다. 고유 전체 일치, 모호한 검색 거절, 대시 정규화, 시작 경계 포함·끝 경계 제외·미상 시각 차단의 6개 assertion이 성공했다. 코드의 함수 단위 결과이며 SQLite 저장·FTS 재개 또는 실시간 위임 시험은 아니다.
- **이전 실측 재사용.** TradingAgents 원본 그래프 15개 모의 테스트, 실제 AAPL/MSFT 가격 복기 및 LangGraph SQLite 프로세스 재개, Temporal 이력 재생, 현행 안전·대사 단위 검사는 [기존 결과](06_candidate_final_decision.md)와 [복기 결과](05_market_pilots.md)에 있다.
- **정적 확인.** Hermes의 Bot Mode, Gateway, 모델 라우팅, Cron, 메모리 공급자와 재개 상태는 위 고정 소스와 공식 문서에서 확인했다. 전체 Hermes 서비스·자격증명·실제 모델·실시간 주문·시장 데이터 수집은 실행하지 않았다. 위 A/B는 예정 계약이다. 현재 코드와 전략은 변경하지 않았다.

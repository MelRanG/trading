## 실험 계약

A1은 이미 연구에 사용한 미국 6종목 Yahoo 스냅샷(2020–2024)에서 FinRL 잔차 모멘텀과 63거래일 단순 누적수익 순위를 비교한다. 원래 실행기의 월말 판단, 다음 거래일 수정 종가, 편도 10bp, 첫 거래일부터 동등한 시작 자산, 소수점 수량과 한 종목 100% 한도를 고정한다. 기존 SPY·6종목 동일비중 보유도 표시한다. 단순 모멘텀은 연구 대조군이다. 국내 V79는 다른 시장·상품·실행 계약이라 이 비교의 동일 조건 분기가 될 수 없다. 결과는 재사용 역사·생존 편의 표본의 진단이다.

### A2 · 검증과 제안의 구분

동일 데이터 부족 문제를 두 경로에서 점검했다. 기존 Factory의 기록은 고점 근접도 중복 거절, PIT 뉴스의 실행 가능성 거절, 5일 반전의 진단 거절, 실제 replay 예산 0/1을 보존한다. RD-Agent의 원본 메서드 5개를 모의 구현과 실행했던 결과는 실험 생성→개발→실행→평가→trace 연결을 확인한다. 이 두 결과는 동일 문제에서 실제 제안된 가설의 대조 표본이 아니므로 신규성·구현 가능성·검증 성공률의 비교값은 없다. RD-Agent 의존성 수집 차단과 모의 호출 경로를 [보완 보고서](02_validation_addendum.md)에서 재사용했다. 기존 TradingAgents 복기 검증은 [이전 결과](05_market_pilots.md)를 사용했다.

## B1·B2 · 실제 모델 비교 시도와 데이터 확인

입력 cutoff는 Apple FY2024 Q1 공식 발표 직후(2024-02-01)로 고정했다. 기업명을 X로 가리고 카드 4개를 양쪽에 똑같이 제공했다. C1 매출·EPS, C2 서비스 매출 및 기기 기반, C3 13주 대 14주 비교, C4 영업현금흐름·주주환원과 전년도 Q2 기준을 포함했다. 대조는 표준 분석, 실험은 B1에 촉매 탐색 체크, B2에 실적 시나리오 체크를 각각 적용했다. 호출 1회·180단어 상한과 카드 인용 요구를 맞췄다. 이는 고정 자료 안의 선행 근거 선별 시험으로 설계했으며, 웹 도구의 능동 검색 효과는 별도다. [Q1 발표](https://www.apple.com/newsroom/2024/02/apple-reports-first-quarter-results/) · [Q1 수치 원문](https://www.apple.com/newsroom/pdfs/fy2024-q1/FY24_Q1_Consolidated_Financial_Statements.pdf) · [이전 Q2](https://www.apple.com/newsroom/2023/05/apple-reports-second-quarter-results/)

**실행 상태.** 주요 API 키가 환경에 없었고 Ollama/LM Studio 로컬 포트가 응답하지 않았다. Codex CLI의 ChatGPT 로그인은 확인했다. 기본 설정은 구버전 CLI에서 서비스 등급 파싱 오류가 났다. 커맨드 단위 flex 설정은 API에서 거절됐고, ASCII 임시 작업 디렉터리·읽기 전용·ephemeral에서 실제 A/B를 제출한 두 프로세스가 종료 코드 1을 반환했다. 유효 모델 출력을 수집하지 못해 발견 건수·오탐·중복·예측 오차·모델 비용은 N/A다. 가짜 응답이나 보고서 작성자의 해석으로 채우지 않았다.

같은 격리 경로에서 fast 등급의 연결 probe도 종료 코드 1이었다. 이 실행에서는 stderr를 저장하지 않아 fast 실패의 정확한 원인은 미확인이다. 다음 실행은 B1/B2를 별도 모델 호출로 분리해 각 스킬의 영향이 다른 과제에 섞이지 않게 한다.

**채점 데이터만 확인했다.** 전년 동기 단순 기준선은 매출 $94.836B, 희석 EPS $1.52였고, 발표된 FY2024 Q2는 $90.753B와 $1.53이다. 절대 오차는 $4.083B와 $0.01이다. 이는 입력/라벨과 점수 계산이 가능한지 확인한 결과다. 실험 입력에 Q2 실현치를 넣지 않았다. 이름을 가려도 수치 조합을 모델이 기억할 수 있으므로 역사 예측의 독립성은 미확인이다. 당시 컨센서스와 가격 스냅샷을 이번 카드에 넣지 않아 기대 차이·reverse DCF·현금흐름 예측은 평가하지 않았다. ## 최종 설계에 반영할 변경

- **채택할 설계:** 기업가치와 퀀트의 두 독립 후보 큐를 유지한다. 공통 위험 계층에서 종목 중복 노출·총 위험과 상충 판단을 처리하고 후보를 만든 전략 ID를 보존한다.
- **부분 채택:** 기존 Factory의 provenance·중복·예산 게이트, 검증된 복기 및 시점 차단을 연구 기반으로 둔다. Hermes는 기존 복구 근거에 따라 읽기 전용 조율 후보로 둔다.
- **보류:** 잔차 모멘텀의 교체 도입, RD-Agent 전체 루프, 투자 스킬 묶음. 개발의 첫 작은 산출물은 동일 원문·당시 기대치·예측·실현치·독립 채점의 공통 레코드다. 이후 실제 모델 실행이 가능한 동일 예산 환경에서 촉매 발굴과 시나리오 추정을 각각 한 번 비교하고, reverse DCF와 복기는 별도 제거 실험에서만 효과를 판정한다.

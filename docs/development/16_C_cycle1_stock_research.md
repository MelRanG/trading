## B. 사전등록과 결과

- t일 야간 로그 갭 g와 장중 로그 수익 d를 종가까지 관측한다. 고정 20일 평균 `-g*d/(abs(g)+0.01)`를 높은 값 우선으로 평가한다. t+1 시가~t+6 시가의 H5, 6개 양의 적격 시가와 동일 종목·날짜 마스크를 사용했다. 2023년에 특징만 점검했고 2024년을 이미 노출된 연구 평가 구간으로 사용했다. 미래 가격 변경과 prefix 절단이 과거 특징을 바꾸지 않았다.
- 기존 H1/R0 해시가 일치하는 일봉은 2022년 7월~2024년 말 미국 176종목·629세션, 한국 119종목·614세션이다. 조정 가격·생존 중심 표본이며 전체 시점별 편입과 상폐 처분·기업행사 체결을 검증하지 못했다. 이번 로컬 점검에서 연구에 사용할 수 있는 역사적 분봉·틱·호가 패널을 확인하지 못했다. 시간순 Forward 실행 로그는 장중 호가 재생 자료와 구분했다.
- Factory는 기존 등록·예약·결과 함수를 격리 경로에서 호출했다. 승인 범위는 PROCESS_DIAGNOSTIC_ONLY, 한 아이디어·두 시장·고정식 1회다. Factory가 임의 전략 코드를 선택해 실행하는 기능은 사용하지 않았다. 선택된 고정식은 실험 모듈에서 명시적으로 실행했고 결과를 기존 원장에 연결했다. [계약과 예약](../../runtime/task16_cycle1/evaluation_claim.json)

## C. Feedback과 종료

기존 Task16-B의 시점·출처·연구/경제성 분리 규칙을 통해 두 시장 모두 HOLD / UNDETERMINED를 받았다. 증거는 부분 RankIC·구간, 상위군 리프트, 집중도, 과거 실패 원장이다. US 음의 두 반기와 KR 방향 역전은 고정 양의 방향과 일치하지 않고, 구간은 0을 포함한다. **같은 계열의 다른 식을 예비 후보로 재탐색하지 않고 Cycle을 닫았다.** 독립적인 시점별 코호트와 미노출 사전등록 평가에서 일관된 양의 증분이 확인될 때만 재개를 검토한다. 새로운 원인을 탐색할 경우 새 자료의 검증 범위부터 다룬다. 후속 등록·예약·실행 0건이다. [미국 Feedback](../../runtime/task16_cycle1/US_feedback.json) · [한국 Feedback](../../runtime/task16_cycle1/KR_feedback.json)

## D. 자율 연구 능력과 한계

| 능력 | 관측 범위 |
|---|---|
| 가설 발굴·협업 | 비실시간 모델 두 호출에서 후보 네 건. Team2의 경제 메커니즘과 Team3의 독립 수식 비교를 공동 후보 선정에 사용했다. 동일 모델 두 역할이므로 서로 다른 모델의 독립 검증으로 세지 않는다. |
| 비교·기존 기억 활용 | 실적 전환 표본, 공시 범위, Q3·H1 및 양 팀 후보의 특징 중복을 점검했다. 의미 중복과 신규 식의 최종 선택·Python 번역은 연구 실행자가 수행했다. |
| 실제 연구 | 고정 H5 식 하나를 기존 Factory의 격리 진단 예약에 연결했다. 이미 존재하는 통계 평가 기능을 재사용했다. 수익률을 읽은 뒤 식이나 부호를 변경하지 않았다. |
| 해석·후속·중단 | 기존 Feedback과 모델 자문이 두 시장에서 보류, 새 과제 0건을 기록했다. 예산 내 중단 경로를 확인했다. 자동 의미 중복 검사와 임의 코드의 무인 실행, 신규 투자 알고리즘의 독립 경제성 우위는 미입증이다. |

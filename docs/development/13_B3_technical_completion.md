# Task 13-B3 — 기술 문제 수정·동일 가설 평가 마무리

**기술 수정: `REPAIR_VERIFIED`**  
**평가 유효성: 제한된 SURVIVOR_RESEARCH 범위에서 유효**  
**연구 결과: `NO_INCREMENTAL_EVIDENCE`**

상장일·거래소 이전·티커 변경을 구분해 네 종목의 연구용 적격성을 복구했고, 동일 봉인 신호를 **한 번만 수정 평가**했다. 기존 B3의 DATA_BLOCKED 보고서·임시 통계·가격·계약은 그대로 보존했다. 이번 결과는 가설 전체의 기각이나 독립 알파 검증 완료가 아니라, **현재 표본에서 기준선 대비 증분 예측력을 뒷받침하지 못했다는 제한 진단**이다.

## 2. 실제 최소 수정과 보존

`experiments/task13_b3_repair/eligibility.py`에 연구용 마스크 읽기 경로를 하나로 모았다.

- 검증된4종목: 공식 식별 이력과 기존 기본 품질 마스크의 교집합. 연구 종료일2024-12-31까지만 사용한다. 복구된 적격 세션은 KMB1,366·HLT2,011·PLTR1,070·SGI2,010으로 모두 기존500세션 기준을 만족한다.
- 나머지176종목: 기존 `native_eligibility.csv`와 기본 품질 마스크의 교집합. 확인하지 않은 과거 구간을 임의로 복원하지 않았다.
- 분할·비정상 점프·거래량·결측 경고와 지수 마스크는 그대로 유지했다. 가격 수정·보간·새 다운로드는0이다.
- 원래 평가 코드에는 **마스크 함수 호출1곳과 출력 경로/원계약 연결만** 적용했다. `fitted`의 AST가 원본과 같음을 검증했다. 새 백테스터·학습기·DB·서비스는 없다.

실제 적용 diff는 `runtime/task13_b3_repair/minimal_evaluator.diff`, 실행한 코드 전문은 `executed_evaluator_v2.py.txt`다. R0 원본 파일과 과거 입선 명단/보고서는 다시 생성하거나 덮어쓰지 않았다. 복구 입력은 task-local overlay이며 운영·다른 연구에 자동 적용하지 않는다.

**기술 수정안1회 / 허용2회**, 사전 회귀6건 통과 후 **수정 평가1회 / 허용1회**를 실행했다. `corrected_evaluation_attempt.json`의 원자적 예약으로 두 번째 평가를 차단한다. 결과에 맞춘 재수정·재실험은 없었다.

## 3. 원래 평가와 수정 평가

원계약·146개 봉인 신호·방향+·H60·12기업 후보·2020~2024·통제변수·표본 gate를 유지했다. ETN/JNJ의 재무 입력 부재도 그대로여서 관측 기업은10개다.

신호·기업·사건 ID·진입/종료일·MOM20/REV5/VOL20·개별 주식 수익률이 원래105건과 동일함을 대사했다. 가격/기본 마스크 hash도 동일하다. 별도 적격 마스크를 연결하면서 **SHW10사건의 peer에서 LIN이 기존 native 경계에 따라 제외**돼 업종 상대수익이 바뀌었다. 이는 결과가 나쁜 종목 제거가 아니라 기존 적격성 경로를 일관되게 적용한 입력 수정이다. 검증된 네 종목은 당시 이력대로 유지된다.

| 지표 | 기존 임시값 — 당시 DATA_BLOCKED | 수정v2 — 제한 연구 진단 |
|---|---:|---:|
| 사건 / 기업 / 업종 | 105 /10 /5 | **105 /10 /5** |
| 개선/악화 사건 | 62 /43 | **62 /43** |
| gross 개선−악화 H60 업종 상대수익 차이 | +1.577%p | **+1.533%p** |
| 통제 후 잔차 Pearson | +0.0288 | **+0.0272** |
| 통제 후 잔차 Spearman | +0.00055 | **−0.00147** |
| 이익률1%p 개선당 통제 계수 | +0.0752%p | **+0.0711%p** |
| 기업 cluster95% 구간 | [−0.4376,+0.5881]%p | **[−0.4411,+0.5834]%p** |

통제는 원래의 사전 MOM20·REV5·VOL20·연도·현재 업종이다. 일별 횡단면 RankIC가 아니라 공표일이 다른 사건들을 합친 진단이다. 개선/악화 그룹 평균은 각각 약+0.213%/−1.320%지만, 거래비용 차감 계좌 성과나 실행 가능한 long-short 수익률이 아니다.

시기별 관계는2020·2021년 음수,2022~2024년 양수로 불안정하다. LOW·PEP·ELF를 각각 제외한 사전 민감도에서도 통제 계수가 음수다. 이 결과를 이용해 종목을 제거하거나 방향을 바꾸지 않았다. 수정 전후 입력 hash가 다르므로 전략 개선 A/B 성과라고 주장하지 않는다.

**현재 판단:** 작은 양의 점추정만으로 증분 정보가 있다고 보기 어렵다. 신뢰구간은0을 포함하고 순위 잔차 관계도 거의0이다. 비용 후 경제성이나 Task15·Forward 진입을 뒷받침하는 결과는 아니다. 동시에 이 제한된 실험으로 영업이익률 정보 전체가 무용하다고 입증한 것도 아니다.

## 4. 검증 수준과 남은 한계

- **해소:** 네 종목의 정체성/시장·티커 시작일 혼동, 기본/상장 이력 마스크 경로 불일치, 과거 TPX 식별 누락. 원 B3 manifest114파일의 변경·누락0, 원 신호·계약·평가 hash 보존.
- **제한 연구 평가 유효:** 수정된 입력의 출처·시점 정렬·105건 H60 label·가격/신호 불변성 확인. 공식 Paper/Live 또는 시장 전체 PIT 적격성 인증은 아니다.
- **미해소:** 생존기업·현재 업종 표본, 전체 원접수번호 재무의 원문 전수 대사 부재, 기업행사/실행 가격의 부분 검증, 소수10기업·중첩 H60·공통 시점 충격, 관측 세션 달력, 거래비용/회전율 미평가.
- 네 종목 밖의11개 native 경계 차이는 새로 추정해 풀지 않고 기존의 보수적인 마스크를 유지했다. 이 중 이번 peer 구성에 영향을 준 종목은 LIN이다. 그 처리까지 포함해 **제한된 연구 패널**로 해석해야 하며, 완전한 역사적 시장 유니버스라고 확대하지 않는다.

수정 후 회귀 **8건**, AGENTS 필수 안전 회귀 **24건**, compileall 통과. 필수 회귀는 기존 방식대로 현재 코드/설정/데이터 hash가 같은 격리 snapshot에서 원래 테스트를 실행한 뒤 임시 복사본을 제거했다. 테스트 통과와 투자 성능은 분리했다.

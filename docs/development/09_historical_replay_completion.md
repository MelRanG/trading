## 1. 확보 자료와 실제 사용 경로

### 한국

- [KRX 공식 카탈로그](https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd)와 [이용 절차](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp)는 서버에서 HTTP 200. KOSPI/KOSDAQ 일별지수, 유가증권/코스닥 전종목 일별매매정보와 종목기본정보 6종 명세를 보존했다. 공식 제공 범위는 2010-01-04 이후이며 `basDd`로 조회한다. 기본정보의 기준일 조인도 확인했으나 이것이 배당·분할·상폐 정산 원장을 대체하지는 않는다.
- 정규 API는 미인증 요청에 **401 Unauthorized Key**. 현재 환경에 승인된 KRX 키는 없다. 회원 가입·본인 확인, 인증키 신청 승인, API별 활용 신청 승인이 필요하다. DART 키를 KRX로 전달하지 않았다.
- 공식 상세 UI가 공개하는 **샘플 전용 인증과 `/svc/sample/` 경로**는 HTTP 200·응답 10행이었다. 정규 API에 샘플 인증을 사용하지 않았다. 이 표본의 실제 일자/휴장 응답으로 한국 거래 세션을 점검했으며, 전종목 목록이나 KOSPI 전체 지수로 오인하지 않았다. 지수 샘플의 KOSPI100 등을 KOSPI로 치환하지 않았다.

- 솔루엠 248070 식별은 당시 공시와 [2021-05-31 증권사 원문](https://www.eugenefn.com/common/files/amail/20210531_248070_kyoungkt_627.pdf)으로 보강했다. 후자는 식별 근거이며 예측 정답으로 쓰지 않았다.
- 솔루엠은 2021년 연간·2022년 1분기 원문으로 보유구간의 무배당 및 발행 이력을 평가자만 확인했다. 이 사후 원문의 영업 실적은 연구 입력에 제공하지 않았다. 전체 기업행사 엔진의 완성으로 해석하지 않는다.

## 2. 봉인한 연구·가치평가·투자 판단

공유 정보 종료 시각은 **2021-11-30 23:00 UTC**다. 미국 11월 30일 종가 공개 후이며 한국 12월 1일 개장 전이다. 초기 계약의 15:00 UTC는 미국 종가를 사용할 수 없어 **모델 실행 전 V2**로 바로잡았다. 후보·기간·비용을 사후 수익에 맞춰 변경하지 않았다.

A는 기업가치, B는 당시 제한된 금리·시장 가격 맥락, C는 동일 대안과 현금을 비교했다. A의 최초 분석을 보존한 후 B/C를 순차 실행했다. 동일 세션 입력 해시:

`a739de154cc74bdfed49caf1eb3a13865ef69c00cae80f6341c49e7b6c98423c`

| 기업 | 당시 기준 가격 | Bear / Base / Bull 조건부 주당가치 | 실제 판단 |
|---|---:|---:|---|
| 솔루엠 | ₩23,050 | ₩5,077 / 18,000 / 38,077 | A/B/C 모두 WAIT, 0% |
| ON | $61.43 | $24.33 / 65.16 / 95.57 | A/B/C 모두 WAIT, 0% |

이는 **2022년 실적 가정에 EPS×배수를 적용한 시나리오**이며 63세션 뒤 목표주가나 확률 예측이 아니다. 솔루엠 Base는 순익 520억원·희석주식수 5,200만주·18배, ON Base는 순익 $1.44bn·442백만주·20배 가정이다. EPS 방식은 이미 주주가치이므로 부채를 다시 차감하지 않았다. 완전한 순부채·주주 청구권 연결과 독립적인 수요 증거가 부족하다는 한계를 기록했다.

솔루엠은 재고·음의 영업현금흐름과 Base 하락 여지, ON은 약 6%의 조건부 Base 상승 여지에 비해 큰 Bear 위험으로 기권했다. B의 시장 정보와 C의 대안 비교는 행동·비중을 바꾸지 않았다. **A/B/C의 증분 성과 차이는 0이며, 대안이 시장별 한 개여서 상대선택 능력은 충분히 시험하지 못했다.**

원본 Vibe 고정 커밋 `0025531f005d4a7aac3fb884cda2fba9318e7158`의 ChatLLM 구성요소와 기존 Task 8b worker/transport를 재사용했다. 전체 Vibe screener/Research Autopilot이 자율적으로 전체 시장을 탐색한 실행으로 주장하지 않는다. 네트워크 없는 격리 컨테이너에서 고정 입력을 제공했다. 연구에는 이후 가격·기업 실현 실적을 제공하지 않았지만 LLM 자체의 역사 지식은 제거할 수 없다.

Terra 실제 호출 **3회 성공, 알려진 사용량 149,105토큰**. 별도 유료 API 구매는 없었으며 구독 사용량을 임의의 달러 비용으로 환산하지 않았다. 호출 수 제한은 적용했으나 엄격한 생성 토큰 hard cap은 아니다. A/B/C의 입력 길이·토큰 사용량은 같지 않으므로 같은 비용의 효과 비교로 해석하지 않는다.

## 3. 실제 매수·보유·매도 및 지수 대비 성과

기존 `src/quant_harness/investment/research.py:replay_targets`의 D-1 수량 산정·다음 open 체결·비용·NAV를 재사용했다. 추가한 `experiments/task9_completion/replay.py`는 고정 주식수를 유지하고 마지막 open에 청산하는 얇은 연구 어댑터다. 매일 비중을 맞추려고 거래하지 않았다.

목표 비중 2.5%와 실제 open 노출은 다르다. 미국의 D-1→open gap으로 2.522%가 됐으며, 대조군의 별도 사전등록 초기 상한 20% 이내다. 이를 2.5%로 위장하지 않았다. AI PROBE는 실제 open/post-cost 노출 2.5% 초과 시 저장 전 차단한다. 이번 AI PROBE는 없었다.

계좌가 약 97.5% 현금이므로 지수 100%와 단순 비교하면 효과를 과장한다. 노출 일치 비교도 gross 지수 대조군이며 종목당 한 번의 작은 역사 거래일 뿐이다. 매수·매도 후 현금은 각각 ₩9,994,657.5068와 $99,966.4462로 대사된다. 종목별 기여는 해당 한 종목 net 손익과 같다.

한국 매수 1.5bp, 매도 24.5bp(가정 수수료 1.5+당시 매도세금 23), 미국 양방향 1bp를 사용했다. 한국 세금 근거는 [당시 정부 안내](https://www.korea.kr/briefing/policyBriefingView.do?newsId=148881822)다. 양 시장 half-spread 5bp·ADV 참여 기반 impact를 추가했다. **실측 호가·실제 브로커 청구 비용이 아닌 사전 고정 비용 가정**이다. 기존 운영 비용 설정은 변경하지 않았다.

결과: `runtime/task9_completion/results/summary.json` 및 시장/모드별 `result.json`, NAV·체결·미체결 CSV. 기존 엔진의 `_krw` 열 이름은 미국 계좌에서 USD 수학으로 쓰였음을 메타데이터에 표시했으며 두 통화를 합산하지 않았다.

## 4. 단계별 성능 평가와 실패 원인

| 단계 | 실제 확인한 것 | 남은 한계 |

| 발굴 | 당시 공시/실적발표에서 제한 코호트 구성, 시총·행사·자료로 선별 | 전시장 독립 탐색·시점별 상폐 포함 대표성 미검증 |

## 5. 원장·복구·시험과 재현

전용 기존 역사 연구 DB `quant_task3_task9_history`에 판단 3건·최초 결과 8건·체결 4건을 저장했다. 운영 DB·전략·Live 잠금은 변경하지 않았다. 후속 요청 `HISTORICAL_COMPLETION_FOLLOWUP`은 이 연구 DB의 기존 Queue에 등록했다. **공식 Factory의 신규 예약·실험 실행이나 예산 우회를 수행한 것은 아니다.** 기존 예산·우선순위 대기는 유지한다.

최초 export에서 PostgreSQL JSONB가 `-0.0`을 `+0.0`으로 정규화해 현금 결과 6건의 기존 Store payload 해시가 달라지는 문제를 발견했다. 읽기 전용 SQL 재현 시험을 추가했다. 전역 Store나 운영 코드를 수정하지 않고, 실험 안에서 zero를 canonicalize한 V2 결과 8건을 **추가**하고 원본 payload·hash·실행 로그를 보존했다. 기존 6건은 정확한 원본 파일과 SHA를 검증해 재수화한 export로 읽는다. 금액·성과·원본 payload/hash를 수정하지 않았다.

**잔여 호환성 제한:** 이 연구 DB의 V1 signed-zero 결과는 기존 generic `Store.get/export`로 정상 round-trip되지 않는다. 소비자는 canonical V2 또는 `research_records_recovered.jsonl`을 사용해야 한다. 해당 공유 저장소 호환성 버그는 별도 버그 수정 대상으로 남긴다.

| 실제 시험 | 결과/근거 |
|---|---|
| 신규 리플레이·현금·결측/행사 차단·벤치마크 구간·JSONB 재현 | 6 PASS, `evidence/replay_tests_canonical.log` |
| AGENTS 지정 4개 안전 회귀 파일 | 24 PASS, `evidence/safety_tests.log` |
| compileall | PASS, `evidence/compile_final.log` |
| 동일 봉인 연구로 반복 실행 | 신규 체결 0, 같은 결과 8·총 체결 4 유지 |
| 연구 DB dump→새 격리 DB restore | canonical 결과 8·고유 체결 4 검증, `recovery_verification.json` |
| 기존 Forward 보존 확인 | 계획 2개 worker hash 불변, KR/US 기존 계좌 체결 0·현금 유지, 타이머 active |
| 실제 서버 재부팅 | 미실행 |

새 DB 복원 대상은 `quant_task3_completion_restore_091038`이다. dump는 후속 Queue 등록 직전 상태이며 후속 요청 자체는 `followup.json`과 원 DB에 별도 보존했다. 실제 재부팅 검증으로 과장하지 않는다. 기존 운영 경로 변경이 없어 전체 운영 회귀와 이미 완료한 과거 실험을 반복하지 않았다.

최초 실패도 보존했다: 잘못된 로컬 socket 경로/준비 순서, 과도하게 엄격한 공급자 소수점 검사, KOSPI 종가 결측, JSONB signed-zero export. 실패 상태를 통과로 바꾸지 않고 수정 후 별도 재실행 로그를 남겼다. 신규 시험에는 pandas dtype FutureWarning 1건이 있으며 실패는 아니다.

재현(저장된 자료와 기존 격리 DB를 사용; 모델 재호출 불필요):

```bash
.venv/bin/python -m compileall -q src scripts tests experiments/task9_completion
PYTHONPATH=src PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest -q experiments/task9_completion/test_replay.py
.venv/bin/python experiments/task9_completion/run_pilot.py
.venv/bin/python experiments/task9_completion/verify_preservation.py
```

모델 입력은 `prepare_research.py A/B/C`, 실행 경계는 `run_model.sh`·`model_relay.py`에 남겼다. 이미 봉인된 출력이 있으면 재사용하며 덮어쓰지 않는다. 새 연구에는 새 버전·예산·경로가 필요하다. 원본 환경·컨테이너는 기존 Task 6 환경을 재사용했다. 이번 임시 모델 relay는 실행 후 종료했고 상시 scheduler를 추가하지 않았다.

## 6. 5년 확장 가능성과 Task 9 개선 순서

1. **후보 확대:** 전종목 다운로드 대신 같은 시총 하한을 유지한 여러 산업의 소규모 당시 코호트를 추가한다. 제외 기업의 조정 가격·배당 문제를 해결해 실제 상대 선택을 가능하게 한다. 결과를 좋게 만들기 위한 종목 교체는 하지 않는다.
2. **자료 적격성:** KRX 정규 승인 키가 있으면 공식 기준일별 필요한 자료만 수집한다. SEC는 정상 접근이 복구될 때까지 공식 IR의 원문 확보 범위 안에서 제한한다. 뉴스·컨센서스·개정·상폐·기업행사는 별도 적격성 확인이 필요하다.
3. **연구 평가:** 신규 실적 시나리오와 당시 단순 추세·가이던스를 독립 채점한다. 2022년 실적 가치 가설과 63세션 수익을 같은 예측 대상으로 혼동하지 않는다. LLM 역사 지식 위험이 없는 신규 Forward를 함께 쌓는다.
4. **실행·저장:** 배당·분할·상폐 정산과 signed-zero 공유 저장소 호환성은 각각 별도 버그/기능 작업으로 검증한다. 현재 무배당 2종목의 성공을 일반화하지 않는다.
5. **확대 판단:** 이번에는 한 기준일·두 시장만 수행했다. 다섯 시점의 완전한 투자 재현·분기별 5년 롤링·독립 투자 우위는 미완료다. 현재 결과를 신규 Forward나 깨끗한 Holdout으로 집계하지 않는다.

후속 요청에는 이 한계와 필요한 자료·예산을 넣었으며 자동 Champion/Live 승격은 없다. 기존 Task 8b의 실제 Forward 관측은 유지한다.

# Quant Harness 연구 인수인계

## 요청과 목표

연구 책임자 관점에서 기존 판단을 독립 검토하고 개별주 투자 알고리즘의 경제성을 검증할 다음 연구의 우선순위를 제안한다. 사용자 의견과 기존 설계를 모두 검증 대상으로 취급한다.

한국·미국 개별주의 기업·산업 연구, 독립 퀀트 연구, 선정, 진입·추가매수·청산·재진입, 포트폴리오 위험관리와 결과 복기를 연결하는 시스템이 목표다. Python은 실시간 판단과 주문을, LLM은 비실시간 연구와 복기를 담당한다. ETF는 시장 정보와 동일 자본 성과 비교에 사용한다.

독립 검증 전 상태는 ALPHA_NOT_VALIDATED다. 실제 주문과 Forward·Paper·Live 승격은 별도 승인 범위다. 현재 역사 연구 자료는 일봉과 생존 종목 중심이며 시점별 종목군·상장폐지 처리와 실제 경매 체결에 공백이 있다.

## 실제 구현

- Team2 기업·공시 경로와 Team3 독립 계량 연구 경로가 존재한다. 통합 자율 연구의 경제적 효용은 미입증이다.
- Research Factory는 등록·예약·결과 기록 및 제한된 진단을 지원한다. 단일 오프라인 경제성 worker 경로가 추가됐으나 실자료 실행은 미완료다.
- Review와 Task16-B Feedback은 구조화된 증거와 실패 이력을 읽고 제한적 보류·기각·진단 제안을 수행한다. Feedback 적용 전후 투자 NAV의 Task17 A/B는 미실행이다.
- QuantaAlpha, RD-Agent, Vibe 원본 기능을 실험별로 활용했다. full controller, 개별 구성요소, adapter의 실제 실행 범위는 각 원장으로 확인한다.

## 주요 연구 결과

- MOM63 R4 비용 후 +157.26%, R5 +110.19%는 2026년 생존 표본을 사용한 노출된 역사 성과다. R5 여름 구간 −29.22%, 전체 MDD −31.14%였다. R6에서 2023년 기준 예비 후보 435종목을 확인했으나 역사적 후보군의 적격 경제성 재평가는 불가능했다.
- FLOW5 50:50과 R1 순위 완충은 해당 비교 조건에서 증분 경제성을 입증하지 못했다.
- QuantaAlpha Q0/Q1, RD_SMALL, H1은 해당 비교에서 우위를 입증하지 못했다. ST는 정의·자료가 차단됐고 PTH×TO는 자료·검정력이 부족했다. MA20 조건부 이격도는 한국 증분 실패, 미국 불확실이며 EPS 변화는 미국 불확실·한국 자료 차단이다.
- Cycle 1 개장 충격 흡수는 증분 우위 미확인이다. Cycle 2 Vibe academic_retskew의 미국 H20 부분 RankIC는 −0.00065, 95% 구간은 −0.0382~+0.0376이었다. Cycle 3은 QuantaAlpha 계획기를 사용하고 체결 근거를 진단했다. 각 Cycle은 비용 후 신규 정책 경제성 실험을 완료하지 않았다.

서로 다른 전략·시장·기간·비용 계약의 결과를 그대로 합산하지 않는다. 미확인, 자료 차단, 특정 사양의 실패를 구분한다.

## 최신 실행 상태

2026-11-26 UTC 기준 경제성 연구 REVIEW-cc8630ae4ff206cb3ebdae46가 공식 Factory에 등록됐다. R5 진입 후보 29건에서 5거래일 보유 후 다음 적격 시가부터 청산하는 정책을 동일 진입 단순 보유 및 기존 정책의 매도·축소와 비교하는 조건부 에피소드 연구다. 기존 명목가격 체결기, 미체결 추적과 비용 2배 민감도를 사용한다. 21세션 달력 블록은 최대 8개다. 연속 계좌 CAGR이나 독립 알파 검증이 아니다.

11월 26일 UTC Factory 진단 1회 예약 한도는 Cycle 3에서 이미 사용됐다. 경제성 실행은 예약 단계에서 차단됐고 worker 결과와 경제성 기반 Feedback은 없다. 다음 UTC 날짜의 잔여 슬롯 및 실행 상태는 실제 원장으로 재확인해야 한다. 일일 제한 제거는 확인되지 않았다.

## 검증과 주의 사항

최신 작업 기록에서 합성 worker와 Review 회귀는 22건 통과·6건 미실행이다. 확장 안전 회귀는 42건 통과·11건 실패이며 실패는 삭제된 과거 reports 파일 참조와 관련된다. V104 Forward 확인은 NO_ENABLED_CANDIDATES, append 0건이었다. 테스트 통과는 투자성과의 증거가 아니다.

작업 트리에는 사용자가 삭제한 보고서와 기존 수정사항이 포함된다. 기존 자료나 운영 상태를 추측으로 되돌리지 않는다. 이 문서는 인수인계 요약이며 실행 코드·계약·원장이 상세 근거다.
